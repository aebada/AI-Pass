# @ai-pass/web

Next.js application for AI-Pass: marketing site, investor pages, Discovery Hub, and the enterprise workspace.

## Develop

```bash
pnpm --filter @ai-pass/web dev
# http://localhost:3000
```

Key areas under `app/`:

- Marketing and product pages (`/`, `/about`, `/investors`)  
- Workspace (`/workspace/*`)  
- Discovery (`/discover/*`)  
- API routes (`/api/v1/*`)  

See the root [README](../../README.md) and [Developer Guide](../../docs/DEVELOPER-GUIDE.md).
