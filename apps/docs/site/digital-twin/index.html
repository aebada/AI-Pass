Digital Twin

Personalized AI assistant per user — text and voice, calendar awareness, consent-governed memory, and day planning.

Workspace UI

  • Full chat: /workspace/twin
  • Floating widget: available on other workspace pages
  • Voice: Web Speech API (client-side STT/TTS on static production)

Architecture

Browser (static Next.js)
  ├── /workspace/twin
  ├── DigitalTwinWidget.tsx
  └── Web Speech API

API
  POST /api/v1/twin/chat
  GET/POST /api/v1/twin/memory
  GET    /api/v1/twin/calendar/events

packages/digital-twin
  ├── DigitalTwinService
  ├── TwinMemoryStore
  ├── TwinPersonality
  └── CalendarConnector

Package: @ai-pass/digital-twin

ModulePurpose
DigitalTwinServiceChat, plan-my-day, calendar, memory CRUD
TwinMemoryStoreCategories: private, business, medical, connections
TwinPersonalitySystem prompt from profile + memory + schedule
CalendarConnectorGoogle stub + mock demo schedule

Production vs development

Production is static Next.js on Hostinger. Chat UI runs in the browser; API calls hit Laravel endpoints in services/auth-api/routes/api.php (stubs) or the Node dev server for full @ai-pass/provider-hub AI responses.

Membership tiers

Digital Twin features are gated by universal membership tier (memory limits, voice, calendar sync). See docs/DIGITAL-TWIN.md and docs/UNIVERSAL-MEMBERSHIP.md in the repository.
