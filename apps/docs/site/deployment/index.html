Deployment

Hostinger static hosting for the platform and documentation subdomain.

Platform (aipass.space)

Build a static Next.js export and upload via FTP:

./scripts/build-web-static.sh
./scripts/deploy-ftp.sh

FTP credentials via scripts/.deploy-env.local (never commit passwords):

FTP_HOST=92.113.19.130
FTP_USER=u234903558.aipass
FTP_PASS=***
FTP_REMOTE_DIR=/

PHP authentication

./scripts/build-web-static.sh   # COPY_PHP_AUTH=1 optional
./scripts/deploy-hostinger-php-auth.sh

Configure public_html/auth-lib/.env on the server. See Authentication.

Documentation (docs.ai-pass.com)

Build and deploy the static docs site:

./scripts/build-docs-static.sh
./scripts/deploy-docs-ftp.sh

Hostinger hPanel — docs subdomain

  1. Domains → add or connect ai-pass.com to your Hostinger account (nameservers must point to Hostinger).
  2. Subdomains → create docs for ai-pass.com → document root becomes domains/docs.ai-pass.com/public_html.
  3. Set DOCS_FTP_REMOTE_DIR=/domains/docs.ai-pass.com/public_html in scripts/.deploy-env.local.
  4. Run ./scripts/deploy-docs-ftp.sh.
  5. Enable free SSL for docs.ai-pass.com in hPanel → SSL.

Interim option (no ai-pass.com DNS yet)

Until ai-pass.com resolves, use a subdomain on the live domain: create docs.aipass.space in hPanel, set DOCS_FTP_REMOTE_DIR=/domains/docs.aipass.space/public_html, deploy, then update DOCS_URL in apps/web/app/lib/site-nav.ts if needed.

Node.js deploy (VPS / hPanel Node)

For full API routes without static export:

./scripts/build-node-prod.sh
./scripts/deploy-hostinger-node.sh

See docs/DEPLOY-AUTH.md in the repository.
