API overview

REST API scaffold for the AI-Pass enterprise platform.

  • Base URL: /api/v1
  • OpenAPI: /api/docs (Node dev / VPS deploy)
  • Package: @ai-pass/platform-api

Response envelope

  "data": { ... },

    "timestamp": "2026-06-29T12:00:00.000Z",
    "version": "v1"
  }
}

Invoice AI

Vertical app endpoints under /api/v1/invoice-ai/* — upload, validate, approvals, fraud, chat.

Full reference: docs/INVOICE-AI-API.md in the repository.

Static production note

The Hostinger static export serves the marketing and workspace UI. Most /api/v1 routes require the Node standalone build or Laravel backend. Use ./scripts/build-node-prod.sh for full API hosting.
