Authentication

Google Sign-In and session management for production and local development.

Two deployment paths

EnvironmentStackNotes
Production (aipass.space) PHP sessions (php-auth/) No Node.js on Hostinger shared hosting
Local dev (pnpm dev:web) Auth.js / NextAuth v5 Full Next.js API routes

Production (PHP auth)

The live site at aipass.space uses PHP sessions deployed to public_html/auth/ and public_html/auth-lib/.

  • Google redirect URI: https://aipass.space/auth/google-callback.php
  • Secrets file: public_html/auth-lib/.env
  • Deploy: ./scripts/deploy-hostinger-php-auth.sh

Local development (NextAuth)

cp apps/web/.env.example apps/web/.env.local
openssl rand -base64 32   # AUTH_SECRET

Set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, and AUTH_SECRET in .env.local.

Laravel auth API (optional)

An alternative Laravel stack lives in services/auth-api/ for VPS or Hostinger Node deployments. See repo docs/LARAVEL-AUTH.md and docs/DEPLOY-AUTH.md.

Login URLs

  • Production: aipass.space/login
  • After sign-in: /workspace
