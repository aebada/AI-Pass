Getting started

Run AI-Pass locally and explore the workspace.

Prerequisites

  • Node.js 20+
  • pnpm 9+ (monorepo package manager)
  • Git

Clone and install

git clone https://github.com/ai-pass/ai-pass.git
cd ai-pass
pnpm install

Start the web workspace

pnpm dev:web

Open localhost:3000. The workspace lives at /workspace — agents, Digital Twin, Invoice AI, marketplace, and more.

Environment

Copy the example env for local auth and AI providers:

cp apps/web/.env.example apps/web/.env.local

See Authentication for Google OAuth setup and docs/MULTI-AI-SETUP.md in the repo for provider keys.
