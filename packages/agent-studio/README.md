# @ai-pass/agent-studio

Create, configure, skill, and execute AI agents inside the AI-Pass workspace.

**Routes:** `/workspace/agents`, `/workspace/agents/studio`  
**Docs:** [Agent Studio](../../docs/AGENT-STUDIO.md)

## Scope

- Agent definitions and lifecycle  
- Skill library integration and governance hooks  
- Execution against Provider Hub models  

```bash
pnpm --filter @ai-pass/agent-studio build
```
